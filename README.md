### OSINT Username Finder

Herramienta desarrollada en Python que permite consultar la presencia de nombres de usuario en diferentes plataformas mediante información públicamente accesible.

**Características:**
- Búsqueda en GitHub, Reddit, Twitch, Instagram y TikTok.
- Interfaz gráfica con CustomTkinter.
- Consultas HTTP mediante Requests.
- Extracción de información con BeautifulSoup.
- Procesamiento de búsquedas en segundo plano.

**Tecnologías:** Python · CustomTkinter · Requests · BeautifulSoup4

[Explorar repositorio →](https://github.com/Manutkvs/osint-username-finder)
